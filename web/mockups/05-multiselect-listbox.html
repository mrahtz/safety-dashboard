Native Multi-select Listbox

Standard HTML multi-select for model filtering, with a separate sort dropdown. All native browser behavior: Ctrl+click to add/remove, Shift+click for range.

Pros: Native browser multi-select; keyboard-navigable; no custom JS.
Cons: Ctrl+click is unintuitive; no 'select all' button; limited visual feedback.
