Sidebar Checklist

A persistent sidebar holds model checkboxes and a sort dropdown. Checking/unchecking models instantly updates the table.

Pros: Classic pattern, easy to select any subset, sidebar keeps controls separate from data.
Cons: Takes up horizontal space; may need scroll if many models.
