Model Selection & Sort — UI Mockups

10 interface concepts for multi-model comparison and benchmark sorting.

Mockup 1 / 10
Sidebar Checklist

A persistent left sidebar with checkboxes for each model and a sort dropdown, keeping controls visually separate from the data table.

Mockup 2 / 10
Chip Token Input

Selected models appear as removable chips in a tag-input style box; click '+ add model' to pick from a dropdown of unselected models.

Try it →
Mockup 3 / 10
Row Toggle (Dim Unselected)

Click any model name in the table itself to dim or un-dim that row; all models remain visible with deselected rows at reduced opacity.

Try it →
Mockup 4 / 10
Model Card Strip

A horizontal strip of visual toggle cards above the table; each card represents one model and can be clicked to include or exclude it.

Try it →
Mockup 5 / 10
Native Multi-select Listbox

A standard HTML multi-select element for model filtering (Ctrl+click for multi-select) paired with a sort dropdown — no custom UI needed.

Try it →
Mockup 6 / 10
Checkbox Column in Table

A checkbox column prepended to the matrix table; the header checkbox selects all or none with indeterminate support for partial selections.

Try it →
Mockup 7 / 10
Sort-First, Then Filter

A two-step flow: first pick a benchmark to rank models by, then a ranked checklist lets you pick which ranked models to include in the table.

Try it →
Mockup 8 / 10
Command Search / Add

Click '+ Add model' to reveal a search input; type to filter available models and click to add; selected models shown as removable badges.

Try it →
Mockup 9 / 10
Floating Bottom Bar

Model toggles and sort control live in a fixed bottom HUD bar, leaving the full viewport height available for the comparison table.

Try it →
Mockup 10 / 10
Benchmark-Anchored View

Benchmark tabs at the top rank models by that metric; model chips below show each model's rank and score, and can be toggled in/out of the table.
