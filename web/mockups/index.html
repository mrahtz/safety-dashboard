LLM safety-metrics — UI Mockups 10 concepts

Interactive prototypes exploring different UX patterns for toggling models and sorting benchmark columns in the LLM safety-metrics matrix. Each mockup is fully self-contained — try the interactions, then come back here to compare approaches.

01
Sidebar Checklist
Left panel with model checkboxes and sort dropdown. Classic filter-sidebar pattern keeps controls out of the table area.
Try it →
02
Chip Token Input
Removable model chips with an "add" picker dropdown; sort via clicking benchmark column headers directly.
Try it →
03
Row Toggle (Dim)
Click model row headers to dim or undim them. No separate control panel — the table is the UI.
Try it →
04
Card Strip
Horizontal row of toggle-able model cards above the table. Each card shows inclusion status; sort via a dropdown or column headers.
Try it →
05
Native Multi-select
HTML select[multiple] for models with Ctrl/Cmd+click or Shift+click; sort dropdown alongside. Zero custom JS for selection.
Try it →
06
Checkbox Column
Checkboxes as the first table column; header checkbox selects or deselects all. Sort arrows on benchmark column headers.
Try it →
07
Sort-First Ranked List
Pick a benchmark first to rank models by score, then check which ranked models to include. Two-step flow surfaces context before selection.
Try it →
08
Command Search
Type to search and add models; selected models appear as removable badges. Sort via dropdown. Scales gracefully to many models.
Try it →
09
Floating Bottom Bar
Fixed bottom HUD with model toggle chips and sort select. Table fills the full viewport; controls stay accessible while scrolling.
Try it →
10
Benchmark-Anchored
Click a benchmark then models rank by that score then toggle which to compare. Unified rank-and-select flow; score context drives inclusion decisions.
